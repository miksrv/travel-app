# Geometki — Roadmap

## Концепция

**Позиционирование:** Карта мест, которых нет на картах

**Слоган:** Исследуй мир вокруг себя

**Ядро:**
Авторский краудсорсинговый каталог интересных мест. Не навигатор, не туристический агрегатор. Живые места с историями реальных людей: заброшенное, необычное, красивое — то, чего нет в Google Maps и Яндекс Картах.

**Целевая аудитория:**
Люди, которые ищут необычное рядом и вдали — urban explorers, краеведы, adventure-туристы. Те, кто едет не в Эрмитаж, а искать заброшенную психбольницу или секретный маршрут.

**Структурное преимущество:**
Корпоративные платформы не могут краудсорсить полулегальные объекты, заброшенные места и нестандартные маршруты. Geometki — может. Это преимущество, которое нельзя скопировать.

**Цель:**
1000+ посетителей в сутки. Стать авторитетным источником по необычным местам в рунете — таким, на который ссылаются городские порталы, краеведческие сайты и туристические блоги.

## Use Cases

### UC-01 — Быстрая отметка места на карте

**Контекст:** Пользователь находится на месте (в поле, в лесу, в городе). Видит что-то интересное. Хочет отметить это на карте прямо сейчас, пока не ушёл.

**Проблема:** Текущая форма требует: название, теги, точку на карте, описание, фотографии. В поле это невозможно — пользователь уходит, место не добавляется.

**Желаемый флоу (quick capture):**
1. Нажал `+` в приложении
2. Сфотографировал
3. GPS определил координаты автоматически
4. Выбрал категорию одним тапом
5. Написал короткое название (или пропустил)
6. Готово — место на карте

**Определение координат — приоритет источников:**

1. **GPS из EXIF фото** — если фото сделано с включённой геолокацией, координаты берутся автоматически
2. **GPS устройства** — если EXIF пустой, запрашиваем текущее местоположение через браузер/приложение (подходит, если пользователь ещё на месте)
3. **Ручная отметка на карте** — если оба варианта недоступны, показываем мини-карту с пином: пользователь ставит точку вручную
4. **Без координат** — крайний случай: место сохраняется в каталог, но не отображается на карте. Уведомление: "Добавьте координаты, чтобы место появилось на карте"

**Конфликт с SEO:** Место без описания не несёт SEO-ценности. Поисковик его проигнорирует.

**Компромисс — два режима + авто-stub:**

| | Quick mode (в поле) | Full mode (дома) |
|-|--------------------|--------------------|
| Что вводит пользователь | Фото + категория + (опционально) название | Всё, включая описание |
| Что появляется на сайте | Точка на карте, страница-заглушка | Полноценная SEO-страница |
| SEO-ценность | Минимальная (авто-описание) | Полная |

### UC-02 — Массовый импорт фотографий

**Контекст:** У пользователя на телефоне сотни гео-привязанных фотографий мест, где он побывал. Хочет быстро создать из них новые места на карте — без ручного ввода для каждого.

**Желаемый флоу (bulk import):**
1. Открыл раздел импорта, выбрал несколько десятков фото из галереи
2. Система прочитала GPS из EXIF каждого фото
3. Система сгруппировала фото по близости координат — фото снятые в радиусе ~50м считаются одним местом
4. На экране появилась карта со всеми найденными точками + список групп
5. Пользователь быстро проходит по группам: подтвердил, выбрал категорию одним тапом, при желании написал название
6. Нажал "Создать все" — все места созданы как стабы
7. При необходимости: система предупредила, если место уже существует рядом на карте

**Быстрое обогащение после импорта:**
После создания стабов — интерфейс "быстрого редактора": карточки мест одна за другой, можно листать как в Tinder. Для каждой: добавить название, категорию, короткое описание. Пропустил — следующая. Занимает 1-2 минуты на 10 мест.

**Авто-stub:** При quick capture система генерирует минимальное описание:
> "Место «[название]» расположено в [район], [город]. Категория: [категория]. Добавлено пользователем [X]."

Этого достаточно, чтобы страница не была пустой для поисковика.

**Механика обогащения:** Геймификация мотивирует дополнить место позже — заполненное место даёт больше XP. Уведомление: "Вы добавили место 3 дня назад — добавьте описание, чтобы другие узнали о нём."

## Семантическое ядро

Позиционирование — это идентичность. Семантическое ядро — это реальные запросы, по которым приходят люди. Это разные вещи.

### Кластер 1 — Категория + Город (основной трафик)
Самые частотные и конкурентные запросы. Под них нужны отдельные landing pages.

- `заброшенные места [город]` / `заброшки [город]`
- `интересные места [город]`
- `необычные места [город]`
- `заброшенные здания [город]`
- `старинные здания [город]`
- `природные места [город]`

### Кластер 2 — Карта (дифференциатор)
Запросы с картой — наш уникальный формат, текстовые каталоги это не дают.

- `карта заброшек`
- `карта интересных мест`
- `карта заброшенных мест [город]`
- `интерактивная карта достопримечательностей`

### Кластер 3 — Конкретное место (long-tail, основной SEO-трафик)
Низкочастотные, но высококонверсионные запросы. Каждая страница `/places/:id` — точка входа.

- `[название места] [город]`
- `[название места] как добраться`
- `[название места] фото`
- `[название места] координаты`

### Кластер 4 — Discovery (вторичный, для роста)
Запросы "куда поехать" — более широкие, вытягивают аудиторию путешественников.

- `куда поехать на выходные [город/регион]`
- `что посмотреть в [город] необычное`
- `маршрут по заброшкам [регион]`
- `необычные достопримечательности [город]`
