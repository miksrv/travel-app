# Phase 1 — Редизайн AppLayout

**Статус: ✅ ВЫПОЛНЕНО**

## Цель

Убрать устаревший VK-style левый сайдбар. Перейти на стандартный современный layout: фиксированный header сверху на desktop, фиксированный bottom nav на mobile. Освободить горизонтальное пространство для контента.

---

## Размеры контентной области

| Контекст | Ширина |
|----------|--------|
| Максимальная ширина контента | `1280px` |
| Header | full-width фон, внутри `max-width: 1280px`, центрирован |
| Основной контент | `max-width: 1280px`, центрирован, боковые отступы `24px` |
| Карта (`fullSize`) | 100vw / 100vh — без ограничений |
| Mobile | 100% ширины, боковые отступы `16px` |

CSS:
```css
--content-max-width: 1280px;
--content-padding-desktop: 24px;
--content-padding-mobile: 16px;
```

## Desktop

### Header (фиксированный, full-width)

```
[ Логотип ]  [ Лента ][ Карта ][ Места ][ ... ▾ ]          [ 🔍 ][ 🔔 ][ Аватар ▾ ][ + Добавить ]
```

**Левая часть:**
- Логотип → ссылка на главную
- Основные разделы навигации: Лента, Карта, Места, Пользователи, Достижения
- Если пункты не помещаются при уменьшении ширины экрана — последние прячутся в `...` dropdown. Dropdown обновляется при каждом resize.

**Правая часть:**
- **Поиск** — иконка лупы. При клике: input разворачивается справа налево поверх nav-пунктов. Закрывается по Escape или клику вне.
- **Уведомления** — колокольчик. Badge с количеством непрочитанных. Dropdown с последними уведомлениями.
- **Пользователь** — аватар + dropdown (профиль, настройки, выход). Для гостя — кнопка "Войти".
- **Добавить место** — CTA-кнопка. Всегда видна, не прячется в overflow.

**Поведение при скролле:** header остаётся зафиксированным (sticky).

## Mobile (mobile-first)

### Header (упрощённый)

```
[ Логотип ]                              [ 🔍 ][ 🔔 ]
```

- Логотип слева
- Поиск и уведомления справа
- Никакой навигации — она вся в bottom nav

### Bottom Navigation (фиксированная, full-width)

```
[ Лента ]  [ Карта ]  [ ＋ ]  [ Места ]  [ Профиль ]
```

| Пункт | Иконка | URL |
|-------|--------|-----|
| Лента | activity/feed icon | `/activity` |
| Карта | map icon | `/map` |
| **+** | **большая круглая кнопка** | **открывает форму добавления** |
| Места | places/pin icon | `/places` |
| Профиль | аватар / person icon | `/users/me` (для гостя — `/login`) |

- `+` по центру — визуально выделен (больше, другой цвет, приподнят)
- Активный пункт — подсвечен цветом
- Bottom nav скрывается на странице `/map` (fullSize режим), чтобы не перекрывать карту — либо показывается только иконка карты с кнопкой свернуть

## Что убираем

- `<aside>` с левым сайдбаром — полностью удаляем
- Компонент `SiteMenu` (текущая боковая навигация) — удаляем или переиспользуем
- CSS переменная `--width-menu` — убрать из расчётов ширины `main`
- `menuBarRef` и привязанная к нему логика кнопки "Наверх"

## Что сохраняем

- `fullSize` проп в AppLayout — карта использует его для режима без отступов
- Логику уведомлений — только переносим в новый компонент header
- Логику авторизации — только переносим в UserMenu dropdown

## Технические компоненты

| Компонент | Действие |
|-----------|----------|
| `AppLayout` | Рефакторинг: убрать aside, переработать main |
| `AppBar` / `Header` | Новый компонент или полный переписать |
| `SiteMenu` | Удалить |
| `BottomNav` | Новый компонент (только mobile, `display: none` на desktop) |
| `UserMenu` | Доработать как dropdown в header |
| `SearchBar` | Новый компонент (раскрывающийся input в header) |

## Миграция переменных: variables.sass → CSS custom properties

Файл `client/styles/variables.sass` удалить. Все переменные перенести в `light.css` / `dark.css`.

### Что куда переезжает

| Переменная (SASS) | Куда | Примечание |
|-------------------|------|------------|
| `$fontSizeTitleH1: 1.2em` | `light.css` → `--font-size-h1` | Тема не влияет, только в light |
| `$fontSizeTitleH2: 1.1em` | `light.css` → `--font-size-h2` | |
| `$fontSizeHeadline: 0.9em` | `light.css` → `--font-size-headline` | |
| `$fontSizeParagraph: 0.95em` | `light.css` → `--font-size-paragraph` | |
| `$fontSizeCaption: 0.8em` | `light.css` → `--font-size-caption` | |
| `$boxShadow1` | `light.css` → `--shadow-1` | Проверить — возможно уже дублирует `--popout-shadow` |
| `$boxShadow2` | `light.css` → `--shadow-2` | |
| `$boxShadow4` | `light.css` → `--shadow-4` | |
| `$boxShadow5` | `light.css` → `--shadow-5` | |
| `$overlayBackground` | Не нужен — уже есть `--overlay-background` в обоих темах | Удалить |

### Особые случаи

**`$mobileMaxWidth: 768px`** — CSS custom properties не работают внутри `@media` запросов. Не может стать `--mobile-max-width`. Вместо удаления — перенести в `mixins.sass` как SASS-переменную и использовать только оттуда:
```sass
// mixins.sass
$breakpoint-mobile: 768px
```

**`%placeBottomPanel`** — SASS extend-placeholder, не переменная. Перенести в `mixins.sass` или в стили компонента, который его использует. Найти все вхождения `@extend %placeBottomPanel` перед удалением.

### Попутно обновить в light.css и dark.css

| Переменная | Было | Стало | Причина |
|------------|------|-------|---------|
| `--width-max` | `1260px` | `1280px` | Новый стандарт контентной области |
| `--width-menu` | `236px` | удалить | Сайдбар убираем в Phase 1 |

## SEO-риски

Редизайн layout не затрагивает URL-структуру и контент страниц — SEO-риск минимальный. Нужно убедиться что:
- `<h1>`, мета-теги страниц не сломались после рефакторинга
- Серверный рендеринг (SSR) страниц не изменился
- Карта сайта и robots.txt не требуют обновления
