# Phase 4 — Атрибуты мест

## Цель

Добавить структурированные атрибуты к местам — практическую информацию для исследователя: как добраться, насколько опасно, нужно ли снаряжение. То, чего нет ни в Google Maps, ни в Яндекс Картах.

---

## Принципы

- **Все атрибуты опциональны** — никогда не блокируют создание места
- **Три состояния:** `да` / `нет` / `неизвестно` (по умолчанию — неизвестно)
- **Редактирует сообщество** — любой зарегистрированный пользователь может обновить
- **Временна́я метка** — показывать "актуально на [дата]", если атрибут давно не обновлялся

---

## Набор атрибутов

### Доступность
| Атрибут | Значения |
|---------|---------|
| Можно добраться пешком | да / нет |
| Вход бесплатный | да / платный |
| Доступно ночью | да / нет |
| Сезонность | круглый год / только летом / затопляется весной |

### Условия на месте
| Атрибут | Значения |
|---------|---------|
| Охрана или ограждение | да / нет |
| Требуется снаряжение | да / нет |
| Уровень сложности | 1–5 (шкала) |
| Уровень опасности | безопасно / осторожно / опасно |
| Особая опасность | радиация / обрушение / химия / нет |

### Для кого подходит
| Атрибут | Значения |
|---------|---------|
| Подходит для детей | да / нет |
| Можно с собакой | да / нет |

---

## Как заполняется

**При быстром добавлении (UC-01, в поле):** атрибуты не показываем — не мешаем quick capture.

**На странице места:** отдельный блок "Практическая информация" с кнопкой "Редактировать". Виден всем, редактируется залогиненными.

**Геймификация:** заполнение атрибутов даёт XP — мотивирует сообщество поддерживать актуальность.

---

## SEO и фильтры

Атрибуты открывают новые комбинации фильтров и потенциальные landing pages:

- `/places?category=abandoned&attribute=free&attribute=walkable` → "Бесплатные заброшенные места пешей доступности"
- `/places?attribute=dangerous` → "Опасные места"
