# Phase 2 — Редизайн главной страницы

## Цель

Главная страница должна за 3 секунды объяснить новому посетителю — что это за сайт и зачем регистрироваться. Конвертировать гостя в пользователя. Показать что платформа живая.

**Главная страница — не основной SEO-трафик** (трафик сидит на `/places/:id`), поэтому главное — конверсия и первое впечатление.

---

## Отличия для гостя и авторизованного пользователя

| Блок | Гость | Авторизованный |
|------|-------|----------------|
| Hero CTA | "Зарегистрироваться" + "Открыть карту" | "Добавить место" + "Открыть карту" |
| "Как это работает" (3 шага) | Показывать | Скрывать |
| Финальный CTA-блок | Показывать | Скрывать |
| Остальные блоки | Одинаково | Одинаково |

## Структура страницы (сверху вниз)

---

### 1. Hero Block (full-width, atmospheric)

**Визуал:** Полноэкранный фон — атмосферное фото одного из интересных мест с тёмным overlay. Фото меняется (слайдшоу из топовых мест платформы) или статичное.

**Контент:**
```
[ Атмосферное фото места — full-width с overlay ]

        Исследуй мир вокруг себя

  Карта необычных мест — заброшенные объекты, природные
  локации, исторические места. Находи интересное рядом,
  добавляй свои открытия, исследуй вместе с сообществом.

  [ Найти места рядом ]  [ Открыть карту ]

──────────────────────────────────────────────────────
  1 164 места  •  1 170 исследователей  •  4 130 фото  •  1 694 отзыва
```

**Замечания:**
- `H1` страницы = "Исследуй мир вокруг себя" — слоган, не SEO-заголовок
- SEO-оптимизированный subtitle содержит ключевые запросы: "карта необычных мест", "заброшенные объекты", "природные локации", "исторические места", "места рядом"
- Счётчики — в нижней части hero, белый текст на overlay
- Кнопка "Найти места рядом" — запрашивает геолокацию и открывает `/map` с фильтром по proximity

**Page title (не менять — уже хорошо для SEO):**
> "Интересные места и достопримечательности России | Геометки"

### 4. Лента активности (компактная)

Небольшой блок — последние 5-7 действий сообщества. Как сейчас на сайте, но компактнее.


## Что НЕ делать в Phase 2

- **Маршруты** — не упоминать, раздел не реализован
- **Коллекции** — не упоминать, раздел не реализован
- Не добавлять карту прямо на главную (тяжело для загрузки, есть отдельная `/map`)
- Не перегружать страницу — каждый блок должен быть коротким

---

## Технические заметки

- Hero-фото: брать из базы топовых мест (по рейтингу/просмотрам), SSR для скорости
- Геолокация для "Найти места рядом" — только по клику, не автоматически (UX best practice)
- Блоки для гостей — скрывать через `isAuthenticated` из Redux, не через CSS `display:none` (чтобы не рендерить лишнее)
- Счётчики в hero — статичные (или кешированные), не запрос к API при каждом рендере
